The five checks

  1. File hash matchesSHA-256 of the file you uploaded equals the one that was signed: not a single byte changed.
  2. Signature is validThe RSA-PSS signature over that hash was made with the private key of the certificate in the signature file.
  3. Certificate chains to the VIT Root CAsigner → Issuing CA → Root CA, each link checked (signature, validity, CA rules). Only our root-ca.crt is trusted.
  4. Code-signing certificate, valid when signedExtended Key Usage contains codeSigning, and signed_at lies inside the certificate's validity.
  5. Not revokedThe signer's serial is not on the current, CA-signed CRL. A revoked certificate always fails.
